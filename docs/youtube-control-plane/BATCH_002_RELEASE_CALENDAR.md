## Blocker

The stored OAuth grant holds `youtube.readonly` and `yt-analytics.readonly` only.
Uploading needs `youtube.upload`; scheduling, captions and playlist writes need
`youtube` and `youtube.force-ssl`. None are present, and re-authorising requires an
interactive browser consent that only the channel owner can complete.

Compliance itself is **not** the blocker: two videos on this channel are public, which
proves API uploads on this project are allowed to leave private.
